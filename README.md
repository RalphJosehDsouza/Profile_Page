
# Profile Page

A Vite + React portfolio and case-study landing page for a digital profile, creative work, and professional experience.

## Local development

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm run dev`
3. Build for production:
   `npm run build`

## Production deployment on Vercel

1. Push this repository to GitHub.
2. Open Vercel and import the project.
3. Keep the default Vercel settings for a Vite app:
   - Framework: Vite
   - Build command: `npm run build`
   - Output directory: `dist`
4. Add the project and deploy.

## Notes

- This app is a client-side React build, so Vercel can deploy it as a static site.
- If you want a custom domain, configure it in the Vercel dashboard after the first deployment.
